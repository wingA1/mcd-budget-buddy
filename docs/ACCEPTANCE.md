# 真实验收与证据

状态：到店单品、默认套餐与独立饮料已执行，见 LIVE_VALIDATION.md 和 LIVE_VALIDATION_V2.md；未覆盖案例继续保留为待办。离线单元测试不代替真实 MCP 联调。

## 在已连接麦当劳 MCP 的宿主中执行

1. 导入本项目 Skill，列出工具，读取当前 schema，检查 `query-meals`、`query-meal-detail`、`query-store-coupons`、`calculate-price` 是否存在。
2. 输入“使用麦麦预算官，两个人总预算50元，到店取餐，不要辣”。按提示补充真实位置、选择门店。
3. 检查菜单和餐品详情来源，构建至少2个可行候选并分别真实试算。若该预算无可行候选，记录失败，按用户同意的预算调整继续验证。
4. 确认试算金额含全部费用，优惠券可用，份数满足人数。归一化真实响应，运行脚本或按 Skill 规则筛选。
5. 负向案例：降低到无法满足的预算；换店；过期报价；未知忌口标签。必须拒绝无依据推荐或重新查询，不复用旧店价格。
